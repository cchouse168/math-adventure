# 🧭 數學自學冒險

給國小孩子自學的數學闖關遊戲。依學期分成不同的冒險，題目有**注音**、可以**朗讀**，每一關都有**動畫互動教學**，再打怪獸練習。

## 📲 安裝成 App（PWA）

整個網站是同一個 App，只要安裝一次，之後新學期推出會自動出現在首頁。

- **桌面 Chrome / Edge**：打開連結 → 網址列右側的 **安裝** 圖示，或首頁的「📲 安裝成 App」
- **iPad / iPhone（Safari）**：打開連結 → 分享鈕 → **加入主畫面**
- **Android（Chrome）**：打開連結 → 「⋮」→ **安裝應用程式**

安裝後可以離線遊玩（第一次需要連網）。

## 🗂️ 專案結構

```
index.html        選學期首頁
manifest.json     PWA 設定（site.webmanifest 同內容）
sw.js             離線快取（整站共用）
icon/             App 圖示
g3a/index.html    三上（gXa = X 年級上學期、gXb = 下學期）
```

新增學期：建立 `g3b/index.html`，在首頁把該學期設為可玩，並把路徑加進 `sw.js` 的 `CORE` 清單、更新 `VERSION`。每個學期的進度存在 `localStorage` 的 `math-adventure:<學期代碼>:v2`。

## ✨ 三上內容

19 週冒險地圖、4 個世界（加減森林、九九山、數字城、魔法塔）、18 關 + 4 個魔王。前 9 週先補二年級的進位、退位和九九乘法，第 10 週起是三年級上學期：一萬以內的數、四位數加減、二位數乘一位數、除法、分數、時間、公分和毫米、圓。
