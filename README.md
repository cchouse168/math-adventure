# 🧭 三上數學 自學冒險

給國小孩子自學的數學闖關遊戲，從二年級的基礎一路打到三年級上學期。題目有**注音**、可以**朗讀**，每一關都有**動畫互動教學**，再打怪獸練習。

## 🎯 立即遊玩

👉 **https://cchouse168.github.io/math-adventure/**

![遊戲圖示](icon/icon-512x512.png)

## 📲 安裝成 App（PWA）

- **桌面 Chrome / Edge**：打開連結 → 網址列右側的 **安裝** 圖示，或遊戲右上角的 📲 → 安裝。之後從桌面或開始選單直接開。
- **iPad / iPhone（Safari）**：打開連結 → 分享鈕 → **加入主畫面**
- **Android（Chrome）**：打開連結 → 「⋮」→ **安裝應用程式**

安裝後可以離線遊玩（第一次需要連網）。

## ✨ 遊戲特色

- 🗺️ **19 週冒險地圖**：4 個世界（加減森林、九九山、數字城、魔法塔），共 18 關 + 4 個魔王
- 🧑‍🏫 **先學再打**：每關先玩互動教學（積木、直式動畫、分糖果、時鐘、尺、圓規），再挑戰怪獸
- ✍️ **注音 + 朗讀**：所有題目和說明都有直排注音，按 🔊 可以聽
- 🪙 **獎勵系統**：金幣、連擊、星星、貼紙簿、換角色、連續天數
- 📅 **週進度**：關卡依週數開放，家長可調整或取消限制
- 💾 **自動存檔**：進度存在本機瀏覽器
